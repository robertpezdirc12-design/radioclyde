# 🌙 Nočni express (avtomatska)

**Duration:** 60 min
**Personas:** thomas
**Segments:** quiz
**Repeat window:** 7 days

---

## Description

Nočni blok: mirnejši pop-rock devetdesetih za nočno prehodnost, brez
rubrik — ponoči govor zamenja glasba. Brez vremena in novic: nočni program
je namenoma najtišji del dneva. Popolnoma deterministična oddaja
(način `autoRadio`).

## Hosts

- **Thomas** — kratko najavi blok, potem večinoma glasba.

## Track Selection

- genre: Pop/Rock
- decade: 1990
- exclude: christmas, soundtrack
- Don't repeat the same artist in a single show.
- No track longer than 8 minutes.

## Tone

Potiho; nočna različica predlog `open`/`close` se uporabi samodejno
(`night` blok, velja tudi čez polnoč).

## Track moves

`intro`/`recap` ob vsaki skladbi, kviz v sredini bloka (`quizIntro` /
`quizReveal`).

## Rubrikes

Nič — nočni program brez rubrik. (Vrstica `Rubrike:` v briefu namenoma
manjka; program je čisto glasbeni.)
